==================================================
今回の新機能
==================================================

・日本地図を表示
・写真がある県だけ薄紫になる
・県をクリックすると、その県の写真だけ表示
・選択県は黒くなる
・写真が少し散らばった位置から「ばらばら〜」と入ってくる
・県フィルターとタグフィルターを組み合わせられる
・SHOW ALL JAPAN で全国表示に戻る
・日付 + 都道府県 + 場所を拡大画面に表示
・MOREは12枚ずつのまま

地図には japan-map-js を使用しています。
HTML内でUNPKG CDNから読み込んでいるので、
追加の地図ファイルをGitHubへアップロードする必要はありません。

==================================================
今後、新しい写真を追加するとき
==================================================

例：愛知県・鶴舞公園で2026年9月3日に撮ったカラス

{
  "file": "bird7.jpg",
  "title": "Crow",
  "tags": ["BIRDS", "NATURE"],
  "layout": "",
  "alt": "公園のカラス",
  "date": "2026-09-03",
  "prefectureCode": 23,
  "prefecture": "愛知県",
  "place": "名古屋市・鶴舞公園"
}

重要なのは

"prefectureCode": 23

です。

地図はこの番号を使って写真と県を結びつけます。

==================================================
まだ県が分からない既存写真
==================================================

こうしておけばOK。

"prefectureCode": null,
"prefecture": "",
"place": ""

地図上の県写真にはカウントされませんが、
ALLでは普通に表示されます。

==================================================
注意
==================================================

もしv4のphotos.jsonで撮影日などをすでに書き換えた場合は、
このv5のphotos.jsonで丸ごと上書きするとその編集が消えます。

その場合は先に現在のphotos.jsonをコピーして、
各写真へ以下の3つだけ足してください。

"prefectureCode": 23,
"prefecture": "愛知県",
"place": "名古屋市"

ばらばら具合
==================================================

script.js の

const directions = [
  [-46, 28, -2.5],
  ...
];

ここで
[x方向, y方向, 回転角度]
を決めています。

もっと派手に飛び散らせたければ数字を大きくできます。
