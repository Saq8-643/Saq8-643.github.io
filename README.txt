SAKU PHOTO v3 - JSON版

この版では、写真を増やすたびに index.html や styles.css に「写真の箱」を追加する必要はありません。

【GitHubで置き換えるもの】
- index.html
- styles.css
- script.js

【GitHubで新しく追加するもの】
- photos.json

今ある写真：
- hero.jpg
- photo1.jpg ～ photo12.jpg
は、そのままでOKです。


--------------------------------
写真を1枚増やす方法
--------------------------------

例：photo13.jpg を追加したい場合

1. GitHub に photo13.jpg をアップロード
2. photos.json を開く
3. photos 配列の最後に以下を追加

{
  "file": "photo13.jpg",
  "title": "Night Walk",
  "tags": ["CITY", "NIGHT"],
  "layout": "",
  "alt": "夜の街を歩いたときの写真"
}

※ ひとつ前の写真データの最後にはカンマ , が必要です。


--------------------------------
layout の種類
--------------------------------

"layout": ""
普通サイズ

"layout": "wide"
横長・大きめ

"layout": "tall"
縦長


--------------------------------
タグ
--------------------------------

tags に好きな文字を入れるだけです。

例：
"tags": ["BIRDS", "NATURE"]

新しいタグを使うと、サイト上部のタグボタンも自動で追加されます。

つまり、
"tags": ["CAMP", "NIGHT"]

と書けば CAMP ボタンが勝手に生えます。


--------------------------------
100枚に増えても
--------------------------------

HTML / CSS / JavaScript は基本そのまま。

やることは
・画像をGitHubへアップ
・photos.json に写真情報を追加
だけです。


--------------------------------
大事
--------------------------------

photos.json は JSON なので、

・最後の項目のあとに余計なカンマを付けない
・文字は "ダブルクォート" で囲む
・{ } や [ ] を消さない

この3つだけ注意。

JSONが壊れると一覧が全部読み込めなくなります。
