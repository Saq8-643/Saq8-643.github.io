--------------------------------
今後、写真を追加するとき
--------------------------------

{
  "file": "photo99.jpg",
  "title": "Night Walk",
  "tags": ["CITY", "NIGHT"],
  "layout": "",
  "alt": "夜の街",
  "date": "2026-09-03",
  "prefecture": "AICHI",
  "place": "名古屋市・栄"
}

この形で追加。


--------------------------------
date
--------------------------------

撮影日。
YYYY-MM-DD 形式。

例：
"date": "2026-09-03"


--------------------------------
prefecture
--------------------------------

将来の日本地図と連携するための「県コード」。

例：
愛知県   AICHI
静岡県   SHIZUOKA
長野県   NAGANO
東京都   TOKYO
神奈川県 KANAGAWA
沖縄県   OKINAWA

英大文字で統一するのがおすすめ。

撮影場所不明なら
"prefecture": ""

でOK。


--------------------------------
place
--------------------------------

人が読む撮影場所。

例：
"place": "名古屋市・鶴舞公園"
"place": "浜松市・弁天島"
"place": "飯田市・しらびそ高原"

将来もっと細かく検索したくなっても使える。


--------------------------------
将来の日本地図
--------------------------------

たとえばSVGの愛知県部分に

id="AICHI"

を付ける。

クリックしたら、

photos.filter(photo => photo.prefecture === "AICHI")

とすれば、愛知県で撮った写真だけ取り出せる。

つまり今回から prefecture を入れておけば、
写真が500枚になってから県情報を足す必要がない。
